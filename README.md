# AI-Powered Job Recommendation System

This system uses AI techniques to match candidate profiles with relevant job roles. It reduces manual job searching, improves recommendation accuracy, and provides a faster, more personalized career guidance experience.

## 🚀 Live Demo
You can view the live application here:  
**[https://ai-powered-job-recommendation-system-z9c7.onrender.com](https://ai-powered-job-recommendation-system-z9c7.onrender.com)**

## ✨ Features
- **Resume Analysis**: Upload your resume (PDF) and the system extracts your technical skills automatically.
- **Job Recommendations**: Get direct links to relevant job openings on LinkedIn, Naukri, and Indeed.
- **Skill-Based Course Suggestions**: Tailored course recommendations to help you bridge skill gaps.
- **User Authentication**: Secure signup/login system to manage your profile.

## 🛠️ Built With
- **Frontend**: HTML, CSS, JavaScript
- **Backend**: Flask (Python)
- **Database**: SQLite
- **Deployment**: Render
